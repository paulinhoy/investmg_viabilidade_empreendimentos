# Pesquisa: estudos de viabilidade de concessões rodoviárias

Objetivo: entender como a **modelagem das receitas** (tráfego, tarifa, praças de pedágio, receitas acessórias)
entra no estudo de viabilidade econômico-financeira (EVTEA) de concessões rodoviárias, para comparar com a
abordagem do PELT-MG usada neste repositório.

| Arquivo | Tema |
|---|---|
| `concessoes_rodoviarias_mg.md` | Concessões rodoviárias estaduais de Minas Gerais (programa de concessões, lotes recentes) |
| `concessoes_federais_antt_mg.md` | Concessões federais (ANTT) com trechos relevantes em MG e os dados abertos da ANTT |

As fontes estão citadas com link em cada arquivo. Os textos foram levantados por pesquisa na internet
e precisam ser conferidos nos documentos originais antes de uso oficial.
